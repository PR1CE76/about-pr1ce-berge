Make it automatic (optional)
  1. Install a userscript manager such as Tampermonkey in the browser where you use chatgpt.com.
  2. Add chatgpt-bridge.user.js from this folder and set the same pair code at the top of the script.
  3. Keep a chatgpt.com tab open. Questions from the glasses are typed in, sent, and the reply is relayed back without you touching the phone.
  4. This automates the ChatGPT web page in your own browser. Check OpenAI's Terms of Use before relying on it. The manual flow above needs nothing extra.
